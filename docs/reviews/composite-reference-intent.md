# Composite reference: intended colour journey

Qing wants the uploaded photographs jointly used to make a **generated neutral-light reference portrait**, not a request for her to choose one original photograph. Keep originals private and intact. The generated result is a best-effort inference from multiple lighting conditions, not verified ground-truth colouring: show the sources and reference privately, label this uncertainty, and let her accept or reject likeness and colour before it is used. The prompt must preserve the same person, face, neck, features and hair; avoid beautification, cosmetic changes or shifting colouring to fit a selected palette. A generated composite cannot prove what colour would be under neutral light.

For drapes, use one consistent face-and-neck crop of the accepted composite on both sides, with the same pixels and crop; continue to label flat swatches as colour juxtapositions, not simulated reflected light. Keep source evidence and individual lighting conditions separate, including conflicting evidence and gaps; never overwrite source photos or automatically derive a certain palette from an inferred image. Existing selected-original reference and uncropped drapes do not meet this intent.

A bounded path is: (1) run built-in qualitative multi-image prompt experiments on nonpersonal reference images; inspect for identity, skin/hair colour drift and source disagreement; (2) show Qing examples and obtain her prompt judgement; (3) with authorised private access to her original photo handles, run a private likeness/colour trial and let her review; (4) implement private composite media plus explicit acceptance and the identical crop, with ownership, deletion, privacy and budget protections. No paid API call until the qualitative prompt is accepted and spending controls are ready. A source account/owned media handle or privately supplied files are required for her own-image trial; never copy her photos into Git or a public demonstration by default.
